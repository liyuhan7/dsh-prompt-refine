# 错误与保护提示清单

本清单依据 `lib/client.js` 和 `lib/index.js` 的当前实现整理，记录原文和触发条件，不改变提示文案或业务流程。

## 展示位置

- 插件操作条内：生成、回填、撤销过程中写入 `panel.error` 的提示，统一使用继承字族、13px、500 字重、20px 行高，允许长文字换行。
- 宿主通知：打开优化面板前的输入/选区检查，通过 `shell.notify('error', ...)` 展示；通知外观由 DSH 控制。
- 一条保护提示可因发生阶段不同出现在以上两种位置。

全文编辑会话会持续同步当前草稿。生成期间编辑会提示「草稿已修改，已停止本次生成；你的修改已保留。」，但不会结束全文会话。选区无法可靠追踪，或全文新增引用时，会停止范围相关写入。当前 Session 新增普通消息提交记录，或输入框进入 `submitting` 阶段时，插件直接关闭面板并清理高亮。

## 输入框与选区（client.js / capture）

| 提示原文 | 触发条件 |
| --- | --- |
| 当前会话没有可用的输入框。 | 输入框状态或操作接口不可用 |
| 输入框正在提交，请稍后重试。 | 当前输入阶段不允许优化 |
| 无法读取当前选区。 | 无法取得有效选区坐标 |
| 选区包含引用，请重新选中纯文本段。 | 选区覆盖引用 chip |
| 没有可优化的文字。 | 选区为空白 |
| 请在 /refine 后输入正文；若含引用，请先选中纯文本段。 | 命令正文无效或包含引用 |
| 没有可优化的文字。请先输入内容，或选中一段文字。 | 草稿为空 |
| 没有可优化的文字。请在 /refine 后输入要优化的内容，或选中一段文字。 | 草稿只有 `/refine` 命令 |
| 草稿含引用或命令，请先选中纯文本段。 | 不允许对当前草稿做全文优化 |

## 草稿、回填与撤销保护（client.js）

| 提示原文 | 触发条件 |
| --- | --- |
| 草稿已变化，请重新开始优化。 | 开启事务时草稿或版本已变化 |
| 选区已变化，请重新开始优化。 | 原始选区与草稿不再一致 |
| 草稿已被编辑或提交，已停止写入；没有覆盖你的修改。 | 后续写入时全文、版本、提交阶段或引用已变化 |
| 结果含不支持的引用占位符。 | 结果含宿主会过滤的引用占位符 |
| 草稿已变化，已停止写入。 | 宿主拒绝此次写入 |
| 回填结果与预期不符，已停止写入；请比较草稿并手动处理。 | 写入后的草稿、版本或引用与预期不一致 |
| 无法可靠追踪当前优化范围，已停止写入；请完成后重新开始。 | 选区优化后草稿文字变化，或全文新增引用；禁用不安全的范围写入 |
| 草稿已修改，已停止本次生成；你的修改已保留。 | 生成期间草稿状态变化，取消当前请求但保留全文编辑会话 |
| 草稿已变化，已停止写入；没有覆盖你的修改。 | 请求完成时当前快照已不同于请求开始时，拒绝回填 |
| 当前内容已经修改，撤销会覆盖你的修改。是否继续？ | 撤销前检测到手动修改，在操作条内显示「确认覆盖」与「取消」按钮；取消不写入 |
| 当前内容已经修改，重新生成会覆盖你的修改。是否继续？ | 重新生成前检测到手动修改，在操作条内显示「确认覆盖」与「取消」按钮；取消不发起请求 |

撤销失败时，原有错误末尾会追加「 可展开原文查看。」。宿主 `insertText` 抛出的异常也可能直接显示。

## 请求与响应流（client.js / generate）

| 提示原文 | 触发条件 |
| --- | --- |
| 请求失败 ({HTTP 状态码}) | HTTP 请求失败且响应中没有可用错误说明 |
| 服务器未返回流。 | 响应没有可读取的 body |
| 模型完成后仍返回数据，未回填草稿。 | `done` 后仍收到数据 |
| 模型返回了无效的结果。 | 流中的文字类型无效，或最终结果为空/包含引用占位符 |
| 模型返回了不完整的数据，未回填草稿。 | EOF 时有未完成的 SSE 数据 |
| 模型未完成响应，请重试。 | 正常读到 EOF，但未收到 `done` |

此外会显示后端 HTTP 错误内容、SSE `failure` 内容，以及浏览器网络异常、JSON 解析异常的原始消息；这些动态文字没有固定完整清单。主动停止或过期请求不会追加模型失败提示。

## 后端输入与模型配置（index.js）

| 提示原文 | 触发条件 |
| --- | --- |
| 会话已失效，请重新选择会话。 | 找不到对应会话 |
| 没有可用模型。请在会话中选择模型或在插件设置中配置备用模型。 | 没有可用模型路由 |
| 请求内容过大。 | 请求体超过限制 |
| 只接受本机同源 POST 请求。 | 请求方法、来源或回环地址检查失败 |
| 需要 JSON 请求。 | Content-Type 不符合要求 |
| 提示词优化已关闭。 | 插件配置为关闭 |
| 输入为空、包含引用占位符或超过 {maxInputChars} 字，请选中纯文本并重试。 | 输入或请求字段检查失败；默认最大输入长度为 12000 字 |

## 后端模型输出（index.js）

| 提示原文 | 触发条件 |
| --- | --- |
| 输出达到 token 上限，请提高预算或缩短输入。 | 模型以 `max-tokens` 结束 |
| 模型未正常完成（{结束类型或“无结束标记”}）。 | 模型没有正常 `stop`，且没有更具体的 Provider 错误 |
| 模型意外返回工具调用，未回填草稿。 | 输出包含 tool-call |
| Invalid optimized prompt: {校验错误代码} | 输出校验失败；当前错误代码为 `empty-output`、`output-too-long` |
| 模型没有返回安全的正文，请重试。 | 输出包含不支持的引用占位符 |
| 请求已取消或超过 {秒数} 秒。 | 后端调用取消或超时；默认 60 秒 |
| 模型调用失败。 | 异常不是 Error 对象时的兜底提示 |

Provider 返回的失败消息、后端 JSON 解析异常也可能直接显示，不能预先枚举。

## 不直接作为界面错误展示的内容

- 「客户端已断开」「模型调用超时」是内部 Abort 原因，通常转换为上面的取消/超时提示；连接已断开时不保证能够送达界面。
- `possible-over-expansion` 只记录日志，不阻止回填，也不是面板错误。
- Diff/高亮降级原因是内部状态，不作为上述错误文案展示。
